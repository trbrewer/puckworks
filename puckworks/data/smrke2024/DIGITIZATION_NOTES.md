# Digitization notes — s41598-024-55831 figure set

Historical method (Figures 2–7; S1 correction below supersedes its old procedure): axis calibration by linear fit to detected tick-mark pixel positions (log10 fit for the Fig4 particle-size axis; max calibration residual 7.6e-4 decades, all linear fits exact to sub-pixel). Marker extraction by strict per-series colour masks and connected-component centroids; overlapping markers split by k-means with k from blob area / median single-marker area, cross-checked against disk-template matching and visual zoom inspection. Fig6/Fig7 text-glyph markers identified by Tesseract OCR backed by template correlation against reference glyphs from the same figure; Fig6 labels additionally validated by cross-panel consensus (the 15 yield positions repeat identically in all four panels). QA: every dataset re-plotted over the source image (see qa_overlays/).
