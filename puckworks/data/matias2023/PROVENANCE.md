# Matias Figure 3 caffeine fraction benchmark

Dataset: `matias2023/fig3_caffeine_fractions`. See SOURCE_NOTES.md for primary
source identities, rights, apparatus, observation operator and recovery contract.
`figure_geometry.json` is the literal source-coordinate authority, including
all decimal tokens and compact source drawing streams. No PDF parser, network
or external mount is required to calibrate it and reproduce the analysis.
`observations.csv` is generated by the task-local offline producer and retains
all ten slots, independent feature support and exact log-coordinate bounds.

Source-derived geometry, observations and annotated source raster: Matias et al.
(2023), DOI 10.1063/5.0176273, arXiv:2304.03161v2, CC BY 4.0.
Changes include coordinate extraction, calibration, annotations and replotting.
First-party analysis code is licensed under the repository MIT license.
Nominal units: mL and mg/L; 1 mL=10^-6 m³, 1 mg/L=0.001 kg/m³.
SE and graphical uncertainty remain separate. Horizontal semantics unresolved.
No common-dose/70-mg normalization, clock/mass mapping, independent validation,
mechanism inference or production adoption. PHYSICAL_VALIDATION=NOT_ESTABLISHED.
