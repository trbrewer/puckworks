normal**. The direct point values use the unchanged observer. I = Delta_c -
(Delta_b + Delta_m + Delta_t), evaluated at the same absolute t,z, never by
subtracting maxima. I is aggregate nonadditivity; it cannot identify pairwise
interactions, and cancellation can make it small.

Common-average analysis integrates each refined piecewise quadratic grain-mean
field over the actual normal physical cells. It splits at fine boundaries,
preserves exact full-cell amounts, and uses the existing polynomial only on
partial overlaps. R_normal then acts on these three projected cell averages.
Every required cell must have common domain support. This representation is
relative to a numerical field, not an exact oracle. Modal tails are not equated.

F_refined(z) - R_normal(A_normal F_refined). Three component cell-average changes,
