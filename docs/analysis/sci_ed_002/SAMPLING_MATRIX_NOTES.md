# Sampling matrix notes

The matrix has exactly six primary rows per validation group. Laboratories are A/B/C/D/A across VG01–VG05 and D for sealed VG06. Organizations are ORG-01/02/03/04/01/02, so four organizations span the programme and none controls more than two groups. Source packages, studies, lineages, base materials, and roast batches are group-unique. Quantitative CIE L* on ground coffee is common to every row; dry-basis roast mass loss is the complementary descriptor. Calibration, replicates, uncertainty, and any categorical mapping are frozen before analyte results.

Bridge aliquots originate from six preregistered open primary units across at least four groups. Reserves and bridge records are maintained outside this primary matrix and excluded from all evidence counts.
