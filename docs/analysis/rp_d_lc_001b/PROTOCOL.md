## 7. The lateral-only bridge

Full geometry in `VIRTUAL_FIXTURE_SPEC.md`. The physics of the change:

The divider is thickened from 2 to 6 base voxels and given a three-layer internal structure —
**port row A | duct row | port row B**. The bridge footprint (`w` base voxels in `x`, centred on
the mirror plane; `kz` base voxels in `z`) is opened in:

- **both port rows** in the **blocked** fixture, and
- **both port rows and the duct row** in the **open** fixture.

Therefore:

1. **The blocked/open difference is EXACTLY the duct-row footprint** — the intended lateral
   connection and nothing else. Asserted as an exact voxel-index set equality at every resolution
   and every candidate.
2. **The lane-facing recesses are common-mode.** They exist in the denominator of `R` as well as
   the numerator, so `R` compares the *same axial network* with the lateral connection off and on.
   That is precisely what the two-node model's `R` means, and it is what 001's blocked fixture did
   not provide. **This is not identical-path subtraction**: no observable is corrected, fitted or
   post-processed; a physically constructible apparatus is built with a physically constructible
   reference. Identical-path subtraction as a *correction* remains forbidden.
3. **Both ports sit at the same `x` footprint**, so traversing the bridge produces no axial
   displacement.
4. **The bridge is axially end-capped**: the divider cross-section immediately outside the
   footprint in `x` is fully solid, so no route through the bridge connects two different `x`
   stations. Proven on the mask by connected-component analysis, not by inspection of a picture.
5. **There is no periodic lateral bypass**: the mask is solid on the whole `y = 0`, `y = ny−1`,

6. **The intended lateral connection exists only in the open case.** Global connectivity cannot
   decide this — the common plenum joins the lanes at both ends by design — so it is decided on the

7. **The mirror and path-swap transforms are exact index operations** on the same array, and the
   `y` layout is palindromic, so the swap maps port row A onto port row B and the duct row onto

The residual axial artifact of this design is **not asserted to be zero**. Topology can guarantee

## 10. Reachable-set protection

The two-node mirror network's forward map is exact
(`WP6-LC-IDENT/DECISIVE_EXPERIMENT.md` §7):

```
R − 1 = [c²/(1 − c²)] · [Ξ/(1 + Ξ)]
```

so as `Ξ → ∞` the signal approaches the hard ceiling `K = c²/(1 − c²)` from below. An observation
above `K` is reproducible by **no** `(c, Ξ)` pair; the inverse absorbs the excess by inflating `ĉ`,
which is exactly what happened at 001's largest aperture (`R − 1 = 0.1338` against `K = 0.1155` at
`c_field = 0.3218`).

**How `c_field` is obtained without circularity.** From the **P0 reference-blocked fixture** only —
a mirror fixture with no bridge structure at all. No open case, no mirror recovery output and no
candidate-specific quantity enters the gate that decides which candidate is frozen. Because the
ports sit in the transition band, symmetric between the lanes and split symmetrically by the bridge
plane, they cancel in the contrast to first order; a conservative `C_FIELD_GATE_ALLOWANCE = 5 %`
reduction is nevertheless applied, and a **smaller** `c` gives a **smaller** ceiling, so the
allowance is strictly conservative for admission.

**The admission test:**

```
predicted_signal + axial_artifact_bound + numerical_uncertainty_bound
        <  reachable_ceiling − frozen_safety_margin
```

| term | value |
|---|---|
| `c_gate` | `0.95 · |c_field(P0 reference blocked)|` |
| `reachable_ceiling K` | `c_gate²/(1 − c_gate²)` |
| `predicted_signal` | `K · Ξ_coupon/(1 + Ξ_coupon)` |
| `axial_artifact_bound` | the candidate's **measured** P1 `|R_identical − 1|`, worst over both resolutions |
| `numerical_uncertainty_bound` | `NUMERICAL_UNCERTAINTY_R_ABS = TOL_MASS_REL = 1e-3` — the frozen mass-conservation tolerance taken at **full value assuming no common-mode cancellation**, which is conservative by construction and invents no new number |
| `frozen_safety_margin` | `0.10 · K` |

**The margin is material and justified by conditioning, not taste.** `d(ln Ξ)/d(ln ε) = 1/(1−ε)`,
so requiring `ε ≤ 0.90` caps the inverse's relative-error amplification at **10×**. The point
estimate is never permitted to sit microscopically inside the ceiling.

At the expected `c_field ≈ 0.32` this admits `Ξ` up to **≈ 7.4**, comfortably spanning the WP6
window `[0.241134, 3.945980]`. A candidate failing the test is **rejected**; if no candidate can
satisfy it, the tranche stops as `DESIGN_BLOCKED_PRE_EXECUTION` rather than authorising primary
computation.

## 11. Anti-circularity contract

**Truth pipeline.** May read prescribed voxel geometry, internal pressure/velocity fields,
transverse bridge flux, calibrated coupons and blocked-fixture internal fields. It **must not call
the WP6 inverse.**

**Boundary-inference pipeline.** Accepts **exactly**
`BOUNDARY_KEYS = {Q0, dP0, q1, q2, dP, orientation, converged}` and **raises** on anything else —
including a missing declared key. It may not receive internal pressure fields, transverse bridge
flux, calibrated `G_lat`, the bridge footprint, `c_field`, `Ξ_field`, mass-flux fields, mask
hashes or any fitted correction; `FORBIDDEN_BOUNDARY_KEYS` names the specific quantities a test
demonstrates are rejected. The function is **imported** from the 001 module, never copied,
rederived or modified, and it delegates to the existing verified inverse.

**Order is load-bearing.** The boundary record is built, the inverse is called and its output
recorded, and only *then* is field truth evaluated.

**Blindness of the freeze.** The bridge candidate and footprint are frozen **before** any primary
mirror recovery output is generated or revealed. P1 runs **identical-path** cases only; the mirror
recovery cases are neither run nor inspected. `FREEZE_RULE` reads coupon-predicted `Ξ` and the
identical-path artifact **only**, and it is applied mechanically:

> From the scientific candidates that (a) pass the artifact budget at **both** resolutions and
> (b) pass the reachable-set admission test, take: the largest coupon-predicted `Ξ` strictly below
> the window; the smallest strictly above; and the candidates nearest three log-spaced in-window
> targets. Deduplicate preserving order. Ties break on smaller `w`, then smaller `kz`.

The driver **refuses `--mode p3`** until the freeze artifact exists **and** its recorded
protocol / fixture-spec / matrix hashes match the configuration about to run. A re-freeze after
review is a new decision, not a repair.

## 20.1 Zero-driver transverse control (supersedes §19.1)

frozen before output at the programme's 0.1 % scale. **For an identical-path control the geometry

## 20.3 Fixed-step re-execution (supersedes §19.5's continuation term)

```
target = CHECK * ceil(CONVERGENCE_AUDIT_FACTOR * base_steps / CHECK)
min_steps = max_steps = target
```

The superseded audit left `min_steps = 2000`, so it could return the base result. Preconditions:

## 19.1 Conservation (supersedes §8's residual definitions)

## 19.5 Numerical discrepancy in `R` (supersedes §10's `NUMERICAL_UNCERTAINTY_R_ABS`)
