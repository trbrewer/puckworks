## 10. Reachable-set protection

The two-node mirror network's forward map is exact
(`WP6-LC-IDENT/DECISIVE_EXPERIMENT.md` §7):

```
R − 1 = [c²/(1 − c²)] · [Ξ/(1 + Ξ)]
```

so as `Ξ → ∞` the signal approaches the hard ceiling `K = c²/(1 − c²)` from below. An observation
above `K` is reproducible by **no** `(c, Ξ)` pair; the inverse absorbs the excess by inflating `ĉ`,
which is exactly what happened at 001's largest aperture (`R − 1 = 0.1338` against `K = 0.1155` at
`c_field = 0.3218`).

**How `c_field` is obtained without circularity.** From the **P0 reference-blocked fixture** only —
a mirror fixture with no bridge structure at all. No open case, no mirror recovery output and no
candidate-specific quantity enters the gate that decides which candidate is frozen. Because the
ports sit in the transition band, symmetric between the lanes and split symmetrically by the bridge
plane, they cancel in the contrast to first order; a conservative `C_FIELD_GATE_ALLOWANCE = 5 %`
reduction is nevertheless applied, and a **smaller** `c` gives a **smaller** ceiling, so the
allowance is strictly conservative for admission.

**The admission test:**

```
predicted_signal + axial_artifact_bound + numerical_uncertainty_bound
        <  reachable_ceiling − frozen_safety_margin
```

| term | value |
|---|---|
| `c_gate` | `0.95 · |c_field(P0 reference blocked)|` |
| `reachable_ceiling K` | `c_gate²/(1 − c_gate²)` |
| `predicted_signal` | `K · Ξ_coupon/(1 + Ξ_coupon)` |
| `axial_artifact_bound` | the candidate's **measured** P1 `|R_identical − 1|`, worst over both resolutions |
| `numerical_uncertainty_bound` | `NUMERICAL_UNCERTAINTY_R_ABS = TOL_MASS_REL = 1e-3` — the frozen mass-conservation tolerance taken at **full value assuming no common-mode cancellation**, which is conservative by construction and invents no new number |
| `frozen_safety_margin` | `0.10 · K` |

**The margin is material and justified by conditioning, not taste.** `d(ln Ξ)/d(ln ε) = 1/(1−ε)`,
so requiring `ε ≤ 0.90` caps the inverse's relative-error amplification at **10×**. The point
estimate is never permitted to sit microscopically inside the ceiling.

At the expected `c_field ≈ 0.32` this admits `Ξ` up to **≈ 7.4**, comfortably spanning the WP6
window `[0.241134, 3.945980]`. A candidate failing the test is **rejected**; if no candidate can
satisfy it, the tranche stops as `DESIGN_BLOCKED_PRE_EXECUTION` rather than authorising primary
computation.

## 11. Anti-circularity contract

**Truth pipeline.** May read prescribed voxel geometry, internal pressure/velocity fields,
transverse bridge flux, calibrated coupons and blocked-fixture internal fields. It **must not call
the WP6 inverse.**

**Boundary-inference pipeline.** Accepts **exactly**
`BOUNDARY_KEYS = {Q0, dP0, q1, q2, dP, orientation, converged}` and **raises** on anything else —
including a missing declared key. It may not receive internal pressure fields, transverse bridge
flux, calibrated `G_lat`, the bridge footprint, `c_field`, `Ξ_field`, mass-flux fields, mask
hashes or any fitted correction; `FORBIDDEN_BOUNDARY_KEYS` names the specific quantities a test
demonstrates are rejected. The function is **imported** from the 001 module, never copied,
rederived or modified, and it delegates to the existing verified inverse.

**Order is load-bearing.** The boundary record is built, the inverse is called and its output
recorded, and only *then* is field truth evaluated.

**Blindness of the freeze.** The bridge candidate and footprint are frozen **before** any primary
mirror recovery output is generated or revealed. P1 runs **identical-path** cases only; the mirror
recovery cases are neither run nor inspected. `FREEZE_RULE` reads coupon-predicted `Ξ` and the
identical-path artifact **only**, and it is applied mechanically:

> From the scientific candidates that (a) pass the artifact budget at **both** resolutions and
> (b) pass the reachable-set admission test, take: the largest coupon-predicted `Ξ` strictly below
> the window; the smallest strictly above; and the candidates nearest three log-spaced in-window
> targets. Deduplicate preserving order. Ties break on smaller `w`, then smaller `kz`.

The driver **refuses `--mode p3`** until the freeze artifact exists **and** its recorded
protocol / fixture-spec / matrix hashes match the configuration about to run. A re-freeze after
review is a new decision, not a repair.

## 20.3 Fixed-step re-execution (supersedes §19.5's continuation term)

```
target = CHECK * ceil(CONVERGENCE_AUDIT_FACTOR * base_steps / CHECK)
min_steps = max_steps = target
```

The superseded audit left `min_steps = 2000`, so it could return the base result. Preconditions:

## 20.4 Candidate-specific evidence (supersedes §19.5's coverage)

Fixed-step evidence for **every selection-bearing case**: each candidate x {blocked, open} x

uncertainty term is non-negative — but it may never admit.

## 20.5 Four frozen bridges (supersedes §19.8's five)

above-window slot is **not required**: clause 2 needs three *in-window* cases, clause 5's

above-window candidate inadmissible under its own safety requirement. "Above" is retained as a
**diagnostic** category. `NO_UNAMBIGUOUS_ABOVE_CANDIDATE` is retired from the required stops.
**The `0.10*K` margin is unchanged and is not tunable to fill a slot.**

## 20.6 Exact forcing identity (supersedes §19's float-carrying rows)

Every forcing-bearing row and record carries `forcing_exact` (numerator and denominator) derived
from `G_REF_EXACT`, plus a lossless `forcing_repr`; the float is obtained only via `row_forcing()`;
and the rational enters `case_id` and row hashing. Twelve **decimal places** keeps only about six
significant digits of a `1e-7` forcing, so a rounded float cannot be the scientific identity.

## 20.7 Records, manifests and a record-derived freeze (supersedes §19.9's lineage)

Immutable atomic case records (never overwritten; exact-match resume or fail closed); validated
phase ledgers that reopen and rehash every cited record and derive P1b/P2a expectations from

the artifact, the `c` interval, the `Xi` envelope and the reachable-set admission from records
alone. It accepts no free-form input, and one record hash may never bind two geometries. Every
uncertainty term records its source case IDs, record hashes, method, interval, overlap status and
final use.

## 20.8 The pre-freeze executor (new)

A real deterministic executor for P0/P1a/P1b/P2a and arithmetic P2b: validate phase -> validate
authorization -> resolve authority -> validate predecessor manifests -> derive rows -> apply
adaptive decisions -> resolve each row to exactly one fixture/coupon -> single guarded call site ->

overwrite, no fallback backend, no looser retry, no automatic tolerance adjustment, no open mirror
before P3. The result provider is a Python-only test seam and is not reachable from the CLI.

## 22.1 Node offsets are extracted, never solved (supersedes §20/§21's diagnostic rows)

The frozen node-surface offsets are re-reads of a field that has already been computed. There is
**no diagnostic row and no provider call**: `node_offset_summary()` is evaluated while the case's
own solution is in memory and retains, per offset, the inlet/outlet/flux plane IDs and exact
coordinates, `Q_volume`, `p_in`, `p_out`, `ΔP`, the **conductance**, the plane fluid-node counts
and finite/nonzero verdicts — plus the source case, mask hash, exact forcing, state, resolution
and candidate geometry. Offset 0 reproduces the case's nominal conductance.

**The per-offset quantity is a conductance, never a ratio.** A same-state `C_j/C_0` is **not** `R`.
`R` is formed only by P2b, and only after an exact open/blocked pairing on candidate, resolution,
forcing level, `tau_plus`, orientation, variant, perturbation, obstruction and run mode, with
identical offset sets and identical plane definitions:

```
R_offset_j = C_open_offset_j / C_blocked_offset_j        R_nominal = R_offset_0
u_pressure_plane_R = SAFETY · max_j |R_offset_j − R_nominal|
```

A missing or unpairable summary **fails** the evidence; it can never contribute zero.

**Solver-invocation contract:** `planned_solver_invocations == normal rows + fixed-step rows ==
n_rows`, and a node-offset summary never increments it.

## 22.2 The lateral pressure control (supersedes §20.2)

Faces must **pair exactly**: identical `x`/`z` bounds, identical shape, elementwise-equal fluid
masks, equal counts, at least one paired node. `both = m1 & m2` is gone — an intersection is not
a pairing, and a control that discards the nodes that disagree cannot establish agreement. All of
`faces_share_footprint`, `masks_pair_exactly`, both counts, `n_paired_fluid` and the paired-mask
hash are **adjudicative prerequisites**.

`p_eff = ρ/3 − g·x` is still evaluated nodewise before pairing. Retained: `mean_delta_p`,
`abs_mean_delta_p`, **`max_abs_delta_p`**, `min/max_delta_p`, `spatial_sd_delta_p`,
`n_paired_fluid` and the axial normalisation.

**`sd/√n` is no longer used adjudicatively anywhere.** LB face nodes are not established
independent samples; the spatial spread survives only as
`SPATIAL_NONUNIFORMITY_DIAGNOSTIC_NOT_A_NUMERICAL_ERROR_BOUND`. The bound comes from each record's
**own fixed-step audit**, and an expected-zero-driver case must clear **both**:

```
(|mean_delta_p| + u_mean_gap + u_ser) / |ΔP_axial|   ≤ TOL_LATERAL_DRIVER_REL
(max_abs_delta_p + u_max_gap + u_ser) / |ΔP_axial|   ≤ TOL_LATERAL_DRIVER_REL
```

**A zero mean produced by cancellation cannot pass while the maximum paired difference is
excessive.**

## 22.3 Gate completeness (supersedes §21's gates)

The forcing verdict asserts the **exact required quantity set at every resolution** —
`Q_open/g`, `Q_blocked/g`, `ΔP_open/g`, `ΔP_blocked/g`, `q_lat/g`, `Δp_lateral/g`, `c_field` —
rather than accepting a nonempty intersection with an allowlist. `q_lat` is a **mass** flux and is

gate compares **actual `Ξ = G_bridge·(1/A1 + 1/A2)`** from exactly matched coupon and
blocked-mirror evidence, never raw `G_bridge` under the name `Ξ`. `TOL_LINEARITY_REL = 1e-4` is
unchanged. **A failed required gate makes the candidate unavailable.**

## 22.4 One scientific classification (new)

## 22.5 Explicit audit and replicate binding (supersedes §21's inference)

## 22.6 P2b persistence, validation and freeze promotion

## 19.5 Numerical discrepancy in `R` (supersedes §10's `NUMERICAL_UNCERTAINTY_R_ABS`)
