# First-assay-conditioned 5-CQA delivery

**TESTED_FIRST_ASSAY_FIVE_CQA_FAMILIES_INADEQUATE.** The measured first original
5CQA assay, together with the first two vial masses, does not achieve the declared
later-fraction adequacy budgets with either tested family. A1 and L1 fail every
primary condition on complete, numerically qualified 48/48 support. No adequate
arm or earned replacement is established. This is a bounded research result,
not a claim about every possible use of an early chemical assay.

A1 analytically normalizes the fixed E0 exponential using the measured first
interval-average assay. L1 adds exactly one assay feature to the D0 five-knot
logistic geometry, with twenty coefficients. L1 improves balanced primary R over
A1 by 0.010927811 mg/g (2.9917%), below the predeclared 0.05 mg/g and 15% margins.
E0/D0 controls reproduce their retained predictions and scores exactly.

The reusable API is strict, immutable and species-tagged. `Model.condition`,
`State.predict_intervals` and `State.remaining_5cqa` require named SI inputs
`m1_kg`, `m2_kg`, `q1_kg_kg`. Saved inference needs no fitting, source corpus,
private evidence directory or network. The first assay is required. Remaining
delivery is modeled between the anchor and supplied stop, not puck inventory.

Nine of twelve primary shots extrapolate the FIT first-assay range; all are
retained and flagged. Flow remains 23/24 supported. Source-internal, target-exposed,
retrospective campaign-separated conditional prediction only; no independent
validation or identified transport, inventory, roast-batch or recipe mechanism.
