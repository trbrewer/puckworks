# Research model card: early-TDS-conditioned 5-CQA

SCI-MD-5CQA-TDS-001 / G1 / NO_GOVERNING_PHYSICS_CHANGE / RESEARCH_ONLY.
[PROTOCOL.md](PROTOCOL.md) fixes the complete mathematics, inputs, development,
numerical qualification, immutable parent, evaluation and decision rules.

S0, S1 and S2 are species-specific 5CQA composition heads over the unchanged
006 C2 TDS concentration. S0 has one bounded constant share; S1 has fifteen
five-knot mass-conditioned logit coefficients; S2 has twenty-five coefficients
including early TDS in the share. S1 also uses TDS through C2. Interval mass
integrates the pointwise parent/share product. The share bound is a modeling
assumption, not measured closure. Historical mass-only E0/D0 remain unchanged.

The strict saved-model API accepts measured first-two-fraction masses/TDS and
mass-coordinate queries after m1+m2. No query-time analyte assay or future TDS.
It returns 5-CQA kg/mg, average mg/g, numerical allowance and support/feature
diagnostics. Remaining delivery is a model integral over the supported domain,
not soluble inventory or a measurement across unassayed gaps.
