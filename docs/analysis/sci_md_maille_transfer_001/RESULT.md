## Why the normalization contract fails

Section 4.5.2 (p.84) describes normalization within each experiment by its
largest measured late concentration. Section 5.5 (p.141 / PDF page 163)
specifies a maximum separately for each replicate, usually at 300/600 s and
occasionally at 60/180 s. It is a selected, noisy measurement denominator, not
an observed equilibrium inventory or one shared pooled denominator.

For replicate r, the observation is `C_r(t) / max_j C_r(t_j)`; the late table
averages these ratios. In general this is not `mean(C(t)) / max_j mean(C(t_j))`.
Table 5.11 provides marginal means and SDs, not the paired reference readings,
selected maxima, reference-time identities or their dependence on numerator
errors. Tables 4.2/4.3 provide some A replicate readings, but not B/C's missing
joins; their A citric absolute values also differ from Table 5.11. No undocumented
repair or substitution is made.

An executable source check compares the 180-second Table 5.10 entries with the
ratio formed from Table 5.11's pooled means. For Omega_B quinic acid the
difference is **−0.0502762431 normalized units**. This is neither a model
prediction error nor a source uncertainty estimate. It shows that silently
replacing the stated observer by a pooled denominator fails to reconstruct
even these published summaries.

A synthetic algebra fixture additionally holds both reference columns' means
and SDs fixed while changing only their replicate pairing. The mean normalized
response changes by **0.0336700337**. This establishes non-identifiability from
marginal summaries, not an empirical bound on this source's error.

Using `G(t)/G(600)` would assume away the selected-measurement operation. Using
the source's assumed equilibrium would add a different unsupported observer.
Neither accounts for selection error. This audit establishes no qualified
mapping or bound sufficient to adjudicate the requested 0.005–0.01 comparison
margins and 0.05 RMSE / 0.025 bias adequacy budgets. A finite set of arbitrary
denominator perturbations cannot certify robustness. We therefore freeze no
scoring observer or treatment set, and choose no favorable alternative.

Table 5.10 already supplies the observed targets. The unresolved step is mapping
a deterministic release response to those replicate-max-normalized observations,
not recovering missing target values. The pooled-summary discrepancy rejects
that particular reconstruction; the synthetic example establishes only that
marginal summaries do not uniquely determine the replicate-normalized result.
Neither diagnostic bounds the source's normalization error, establishes a lower
bound on ranking sensitivity, or proves that no informative bound can exist.
No source-supported mapping or sufficiently informative bound was established
for this specified early/late, selected-maximum protocol. A separately authorized
narrower descriptive observable or independently justified selection bounds
could support a revised question; neither is selected or executed here.

Table 5.10 prints two decimal places; a ±0.005 nearest-rounding allowance is
explicitly an assumption, not a standard deviation. Table 5.11's reported SDs
are retained in the private reference view in mg/L; they are not converted to
independent time-point errors or denominator confidence intervals. No empirical
uncertainty is reported for the early cells. Figure quality/confidence labels
are not calibrated measurement uncertainties.
