# Global evidence-universe implementation

Producer lower-evidence closure is implemented in `governance._validate_global_evidence_universe`; it runs before the no-comparator branch and validates all supplied requirements, contracts, comparisons, predictions, and measurements against typed identities, context, ownership, and an independent contract authority.

Full retained-bundle closure is implemented by `runner._validate_authoritative_bundle_roots` plus the existing exact derivative reconstructions. It binds manifest/card/registry/protocol/case/assumption hashes to repository files, binds execution tree to execution commit, reconstructs explanations and numerical outputs, and rejects extra comparisons, cells, reports, residuals, coverage, gate artifacts, aggregate, decision, or summaries.

Invalid records raise explicit semantic categories; incomplete but valid reached evidence retains C1-R4 scientific semantics.
