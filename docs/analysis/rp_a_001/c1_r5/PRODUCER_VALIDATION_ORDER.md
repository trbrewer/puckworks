# Producer validation order

The producer order is frozen as: parse all collections; primitive validation; typed indexes; duplicate rejection; canonical identity reconstruction; authorized-root construction; global reference checks; context checks; ownership checks; authoritative provenance checks; orphan/extraneous rejection; then applicability, classification, gates, apparatus aggregation, downstream prerequisites, and final decision.

No `evaluate_apparatus` no-comparator return or other scientific early return may occur before global validation. `runner.build_bundle` and `runner.validate_bundle` must apply full-bundle closure, while direct evaluator entry points must receive and validate an explicit independently constructed evidence authority.
