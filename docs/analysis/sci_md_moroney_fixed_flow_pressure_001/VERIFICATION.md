## Cold reproduction

Use a Python environment satisfying pyproject.toml with the `figures` extra;
versions used here are in environment.json. Environment installation is separate
from offline reproduction. No network or private PDF is needed below:

```bash
python -m puckworks.analysis.moroney2015_fixed_flow_pressure --output /tmp/moroney-fixed-flow
python -m pytest -q tests/test_moroney2015_fixed_flow_pressure.py
```

exact rational coordinates. `produce()` reconstructs it from committed numerical
source_objects.json, then produces contrasts, union knots, results, RESULT and
COMPARISON.svg. The original source file need not be present. For calculations
without Matplotlib, use `--no-figure`. All six numerical/text/figure outputs were
regenerated with socket network access blocked and compared byte-for-byte;
[offline_reproduction.json](offline_reproduction.json) records their identities.

uses Figure 12 centers, never a cleaned legacy CSV or Figure 3 substitution.
