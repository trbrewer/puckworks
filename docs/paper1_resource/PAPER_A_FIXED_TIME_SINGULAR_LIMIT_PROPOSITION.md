# Paper A — the fixed-positive-time singular limit proposition (PR-03a)

**Premise:** PR-03a. **Status:** this artefact states and proves the mathematical proposition; the
per-cell verification of its assumptions is generated by
`tools/paper_a_endpoint_construction.py` into `PAPER_A_ENDPOINT_CONSTRUCTION.json`.
**Scope:** MODEL-ONLY. No campaign `y`, `J`, `J_ref`, `J_inf`, threshold, topology, shoulder or
classification appears here or is computed.

This artefact is what licenses the endpoint used by the P0-G8 architecture. It is deliberately
separated into five things that were previously fused:

1. the **mathematical limit proposition** (§2–§5, here);
2. **verification of its assumptions** (per cell, generated, §6);
3. the **numerical construction** of the endpoint (§7);
4. **finite-`κ` diagnostics** (§8) — which are *not* the proof;
5. **declared-cell coverage** (§9).

---

## 1. Objects and notation

For a declared operator-distinct cell (solute, temperature, pressure) the semi-discrete system is
linear in the state with an operator affine in the multiplier:

```
A(κ) = A0 + κ A1,        A0, A1 ∈ ℝ^{n×n}
```

Write

```
m   = dim ker(A1)
N   ∈ ℝ^{n×m}    columns span ker(A1)
L   ∈ ℝ^{n×m}    columns span ker(A1ᵀ),  normalised so that  Lᵀ N = I_m
P   = N Lᵀ
Q   = I − P
A_s = Lᵀ A0 N
```

## 2. Assumptions

**(A1) Fixed finite dimension.** `A0` and `A1` are finite-dimensional and fixed for the declared
cell.

**(A2) Semisimple zero.** Zero is a semisimple eigenvalue of `A1` — equivalently, `A1` has index one
at zero, equivalently `rank(A1) = rank(A1²)`, equivalently `ℝⁿ = ker(A1) ⊕ ran(A1)`.

**(A3) Stable fast spectrum.** Every nonzero eigenvalue of `A1` lies strictly in the open left
half-plane.

**(A4)** `N` spans `ker(A1)`.

**(A5)** `L` spans `ker(A1ᵀ)` and is normalised by `Lᵀ N = I_m`.

**(A6)** `T > 0` is fixed.

Assumptions (A2)–(A5) are verified per cell in §6; (A1) and (A6) hold by construction.

## 3. Two structural lemmas

### Lemma 1 — `P` is the spectral projector, and it annihilates `A1` on both sides

Under (A2), (A4), (A5):

```
P² = P,     ran(P) = ker(A1),     ker(P) = ran(A1),     A1 P = P A1 = 0.
```

*Proof.* `P² = N(LᵀN)Lᵀ = NLᵀ = P`. Since `LᵀN = I_m`, `N` has full column rank, so
`ran(P) = ran(N) = ker(A1)`. From `A1 N = 0`, `A1 P = A1 N Lᵀ = 0`. From `A1ᵀ L = 0` we get
`Lᵀ A1 = 0`, hence `P A1 = N Lᵀ A1 = 0`. Finally `ran(L) = ker(A1ᵀ) = ran(A1)^⊥`, so
`ker(Lᵀ) = ran(L)^⊥ = ran(A1)`, giving `ker(P) = ran(A1)`. Assumption (A2) is exactly what makes
`ker(A1) ⊕ ran(A1) = ℝⁿ`, so `P` is a projector onto the first along the second. ∎

Semisimplicity is load-bearing here and nowhere else in the argument. Without it `ker(A1)` and
`ran(A1)` intersect, no such `L` exists, and the construction has no meaning — which is why §6
tests it rather than assuming it.

### Lemma 2 — adapted block form

Let `W ∈ ℝ^{n×(n−m)}` have columns spanning `ran(A1)`, and let `M` be defined by

```
[N  W]⁻¹ = [Lᵀ ; Mᵀ]      so      LᵀN = I,  LᵀW = 0,  MᵀN = 0,  MᵀW = I.
```

Writing `z(t) = N x_s(t) + W x_f(t)`, the system `z' = A(κ) z` becomes exactly

```
x_s' = A_ss x_s + A_sf x_f
x_f' = A_fs x_s + (κ F + A_ff) x_f
```

with

```
A_ss = Lᵀ A0 N = A_s      A_sf = Lᵀ A0 W
A_fs = Mᵀ A0 N            A_ff = Mᵀ A0 W
F    = Mᵀ A1 W
```

and the initial data split as `x_s(0) = Lᵀ z0`, `x_f(0) = Mᵀ z0`, so that

```
W x_f(0) = Q z0        and        N x_s(0) = P z0.
```

*Proof.* The `A1` blocks are `Lᵀ A1 N = 0` and `Lᵀ A1 W = 0` (both from `Lᵀ A1 = 0`), `Mᵀ A1 N = 0`
(from `A1 N = 0`), and `Mᵀ A1 W = F`. Because the change of basis is a similarity,
`spec(F) = spec(A1) \ {0}` with multiplicity, so **(A3) makes `F` Hurwitz**. ∎

## 4. The fast block decays uniformly in `κ`, with derived constants

### Lemma 3

Let `X ≻ 0` be the unique solution of the Lyapunov equation

```
Fᵀ X + X F = −I
```

which exists and is positive definite because `F` is Hurwitz. Put

```
S   = A_ffᵀ X + X A_ff
κ₀  = 2 ‖S‖₂
γ   = 1 / (4 λ_max(X))
M   = sqrt( λ_max(X) / λ_min(X) )
```

Then for every `κ ≥ κ₀` and every `t ≥ 0`,

```
‖ exp( (κF + A_ff) t ) ‖₂  ≤  M e^{−γ κ t}.
```

*Proof.* Let `B_κ = κF + A_ff`. Then

```
B_κᵀ X + X B_κ = κ(FᵀX + XF) + S = −κ I + S.
```

For `κ ≥ κ₀ = 2‖S‖₂` we have `S ⪯ ‖S‖₂ I ⪯ (κ/2) I`, hence `B_κᵀX + XB_κ ⪯ −(κ/2) I`. For
`x' = B_κ x` and `V = xᵀXx`,

```
V' = xᵀ(B_κᵀX + XB_κ)x ≤ −(κ/2)‖x‖² ≤ −(κ / (2 λ_max(X))) V,
```

so `V(t) ≤ V(0) e^{−κt/(2λ_max(X))}`. Using `λ_min(X)‖x‖² ≤ V ≤ λ_max(X)‖x‖²` and taking square
roots gives the claim with `γ = 1/(4λ_max(X))` and `M = sqrt(λ_max/λ_min)`. ∎

**Every constant here is derived from `F` and `A_ff`.** None is fitted to an observed trajectory or
to an output error. This is the distinction the authorization requires, and it is why §8's numerical
sequence plays no part in the proof.

## 5. The proposition

### Theorem (fixed-positive-time singular limit)

Under (A1)–(A6), for every fixed `T > 0`,

```
lim_{κ→∞} exp( (A0 + κ A1) T )  =  N exp( (Lᵀ A0 N) T ) Lᵀ  =  N exp(A_s T) Lᵀ.
```

Equivalently, for every initial state `z0`, `z_κ(T) → N exp(A_s T) Lᵀ z0`, and consequently every
linear output functional of the state converges.

Moreover there exist constants `C_T` and `M_T`, derived from `‖A_ss‖, ‖A_sf‖, ‖A_fs‖, M, γ, T` and
the basis — and **independent of `z0`** — together with a threshold `κ₁ ≥ κ₀`, such that for
`κ ≥ κ₁`

```
‖ r_κ(T) ‖  ≤  (C_T / κ) ‖z0‖  +  M_T e^{−γ κ T} ‖Q z0‖,   r_κ(T) := z_κ(T) − N exp(A_s T) Lᵀ z0.
```

**Both terms are homogeneous of degree one in `z0`, as they must be.** `r_κ(T)` is a linear function
of `z0`, so replacing `z0` by `α z0` multiplies the residual by `|α|`. An earlier edition of this
artefact displayed the first term as `C_T/κ` with `C_T` claimed to be operator-derived, while the
proof defined `C_T` through `K` and `sup u`, both of which depend linearly on `z0` through
`u(0) = ‖Lᵀ z0‖` and `v(0) = ‖Mᵀ z0‖`. That statement failed the scaling test and is withdrawn; the
`‖z0‖` factor below is carried explicitly through every step.

### Proof

Work in the adapted basis of Lemma 2. Put `u(t) = ‖x_s(t)‖`, `v(t) = ‖x_f(t)‖`, and
`a = ‖A_ss‖`, `b = ‖A_sf‖`, `c = ‖A_fs‖`.

**Step 1 — the fast component is small in `L¹`.** By variation of constants and Lemma 3, for
`κ ≥ κ₀`,

```
v(t) ≤ M e^{−γκt} v(0) + M c ∫₀ᵗ e^{−γκ(t−s)} u(s) ds.
```

Integrating over `[0,T]` and using `∫₀ᵀ e^{−γκs} ds ≤ 1/(γκ)`,

```
∫₀ᵀ v  ≤  M v(0)/(γκ)  +  (M c/(γκ)) ∫₀ᵀ u.                                  (★)
```

**Step 2 — the slow component is bounded uniformly in `κ`.** From `x_s' = A_ss x_s + A_sf x_f`,

```
u(t) ≤ u(0) + b ∫₀ᵀ v + a ∫₀ᵗ u,
```

so Grönwall gives `sup_{[0,T]} u ≤ (u(0) + b∫₀ᵀ v) e^{aT}` and
`∫₀ᵀ u ≤ T e^{aT} (u(0) + b ∫₀ᵀ v)`. Substituting into (★),

```
∫₀ᵀ v ≤ M v(0)/(γκ) + (McT e^{aT}/(γκ)) ( u(0) + b ∫₀ᵀ v ).
```

Define `κ₁ = max( κ₀, 2 M c b T e^{aT} / γ )`. For `κ ≥ κ₁` the coefficient of `∫₀ᵀ v` on the right
is at most `1/2`, so it can be absorbed:

```
∫₀ᵀ v  ≤  (2M/(γκ)) [ v(0) + c T e^{aT} u(0) ]  =:  K / κ.
```

**Factor out the initial state now, not at the end.** Since `u(0) = ‖Lᵀ z0‖ ≤ ‖Lᵀ‖ ‖z0‖` and
`v(0) = ‖Mᵀ z0‖ ≤ ‖Mᵀ‖ ‖z0‖`,

```
K ≤ K_T ‖z0‖,        K_T := (2M/γ) [ ‖Mᵀ‖ + c T e^{aT} ‖Lᵀ‖ ],
```

and `K_T` depends only on the operator, the basis and `T`. In particular, for `κ ≥ κ₁`,

```
sup_{[0,T]} u ≤ (u(0) + bK/κ) e^{aT} ≤ U_T ‖z0‖,   U_T := ( ‖Lᵀ‖ + b K_T/κ₁ ) e^{aT},
```

uniformly bounded in `κ ≥ κ₁`.

**Step 3 — the slow component converges to the reduced flow.** Let `y' = A_ss y`, `y(0) = x_s(0)`.
Then `(x_s − y)' = A_ss (x_s − y) + A_sf x_f` with zero initial difference, so by Grönwall

```
‖x_s(T) − y(T)‖ ≤ e^{aT} b ∫₀ᵀ v ≤ e^{aT} b K_T ‖z0‖ / κ.
```

**Step 4 — the fast component at `T` vanishes.** From Step 1 at `t = T`,

```
v(T) ≤ M e^{−γκT} ‖Mᵀ z0‖ + (M c/(γκ)) sup_{[0,T]} u
     ≤ M e^{−γκT} ‖Mᵀ z0‖ + (M c U_T/(γκ)) ‖z0‖.
```

**Step 5 — assemble.** `z_κ(T) = N x_s(T) + W x_f(T)` and `y(T) = exp(A_s T) Lᵀ z0`, so

```
‖r_κ(T)‖ ≤ ‖N‖ ‖x_s(T) − y(T)‖ + ‖W‖ v(T)
         ≤ (C_T/κ) ‖z0‖ + M_T e^{−γκT} ‖Q z0‖
```

with

```
C_T = ‖N‖ b K_T e^{aT} + ‖W‖ M c U_T / γ
M_T = ‖W‖ M / σ_min(W)
```

both independent of `z0`, using `Q z0 = W Mᵀ z0`, hence `‖Mᵀ z0‖ ≤ ‖Q z0‖ / σ_min(W)`. Since `z0`
was arbitrary the matrix statement follows. ∎

**Scaling check.** Replacing `z0` by `α z0` multiplies `r_κ(T)`, `‖z0‖` and `‖Q z0‖` all by `|α|`,
so both sides scale identically. The withdrawn form failed exactly this check: its right-hand side
did not move when the left-hand side did.

### Required qualification — convergence is **not** uniform at `t = 0`

At `t = 0` the residual is

```
z_κ(0) − P z0 = z0 − P z0 = Q z0,
```

**independent of `κ`.** Therefore, for off-manifold initial data (`Q z0 ≠ 0`),

```
sup_{t ∈ [0,T]} ‖ z_κ(t) − N exp(A_s t) Lᵀ z0 ‖  ≥  ‖Q z0‖  ↛  0,
```

and **no uniform `O(1/κ)` state bound on `[0,T]` may be claimed.** This is the precise error that the
superseded full-state bound archive made: it asserted a uniform bound on `[0,T]` together with an
off-manifold initial state, and those are incompatible.

The two permitted formulations are:

- **fixed-positive-time:** convergence for each fixed `T > 0` — the Theorem above; or
- **uniform on a shifted interval:** for every `δ > 0`, uniform convergence on `[δ, T]`, obtained by
  replacing `e^{−γκT}` with `e^{−γκδ}` in Step 4.

Both are stated; neither is strengthened. A sharp constant is not required and is not claimed,
because this protocol does not estimate a finite tail onset — that is PR-03b, which is
`NOT-PURSUED-CURRENT-PROTOCOL`, and `tail_onset_status = unresolved_by_design`.

### Remark — why the declared output carries no initial layer

The declared output is a linear functional of the state, so it is a **covector**, not a state
vector; it cannot "lie in `ker(A1)`". The precise statement is that the output covector `e_out`
lies in `ker(A1ᵀ)`, equivalently

```
e_out Q = 0
```

— it annihilates the fast subspace. Concretely, the interphase-transfer terms act on the grain rows
only, so the accumulation row is annihilated by `A1` on the left. The output therefore carries no
initial-layer term. This is a remark, not part of the proof: the Theorem already gives convergence
of the whole state at `T`, hence of every linear functional of it. The producer records
`e_out Q` numerically at every cell.

## 6. Assumption verification (generated, per cell)

`tools/paper_a_endpoint_construction.py` verifies, at **every** operator-distinct cell:

**The rank is declared, then verified. It is never discovered.** The structural rank follows from the
model: the reduced state `[c_l, c_s1, c_s2, m_cum]` has dimension `3·nz + 1`, and the
multiplier-carrying interphase-transfer terms act on the `2·nz` grain rows only, so

```
expected_fast_rank    = 2·nz  = 400
expected_slow_nullity = nz+1  = 201
```

the kernel being the `nz` liquid cells plus the accumulated-mass coordinate.

An earlier edition inferred the rank from the **globally largest** singular-value gap and asserted
that a defective zero produces no such gap. That is false. For

```
A1 = block_diag( [[0,1],[0,0]], [−10⁹] )
```

the singular values are `[10⁹, 1, 0]` and `[10¹⁸, 0, 0]`, so the largest gap falls between the fast
block and the Jordan singular value rather than at the nonzero/zero cut; the rule returned rank 1 for
both and reported a **defective** zero as semisimple. The crossover is governed by the gap floor
itself, so the claim that the floor sat above anything a defective operator produces was
self-refuting. Verification at the declared cut rejects the counterexample, because at the true rank
`A1²` has an exactly zero singular value where a retained one is required — which is precisely what
"the kernel grows under squaring" means.

Two failure modes are reported separately rather than collapsed: a **defective** kernel (a retained
slot is exactly zero) and a **numerically undecidable** rank (a retained value falls below
`eps·max(s)`, which occurs when the operator's internal scale ratio exceeds what double precision
resolves after squaring). Both fail closed.

| assumption | test | recorded |
|---|---|---|
| (A2) semisimple zero | `A1` and `A1²` both separate cleanly at the **declared** cut `expected_fast_rank` | separation at the declared cut for both, decidability, last retained singular values, failure reason, the declared tolerance family, and what the withdrawn largest-gap rule would have said |
| rank-source agreement | the structural rank, the SVD null-basis rank and the ordered-Schur fast-mode count must all be the same integer, with the slow pairing nonsingular and conditioned | every source, whether they agree, and a combined verdict |
| (A3) stable fast spectrum | every nonzero eigenvalue strictly in the open left half-plane, by ordered real Schur | `max_real_fast_eigenvalue`, `fast_mode_count`, `spectral_method`, `spectral_tolerance` |
| (A4), (A5) bases and normalisation | projector identities | `‖A1 N‖`, `‖Lᵀ A1‖`, `‖Lᵀ N − I‖`, `‖P² − P‖`, `‖A1 P‖`, `‖P A1‖`, `cond(LᵀN)` before normalisation, `cond(L)` |
| Lemma 3 constants | Lyapunov solve on the fast block | `λ_max(X)`, `λ_min(X)`, `M`, `γ`, `κ₀` |

`cond(N) = 1` is automatic for an orthonormal SVD basis. It may be recorded but is **not** evidence
of operator conditioning; the informative quantities are `cond(L)` and the pre-normalisation Gram.

The SVD rank-separation ratio is **not** the fast spectral decay gap. It is a diagnostic for where
the SVD rank cut falls, and it is recorded under that name.

## 7. Numerical construction of the endpoint

```
N   = orthonormal basis of ker(A1) from the right null space of the SVD
L   = basis of ker(A1ᵀ) from the left null space, normalised by (LᵀN)⁻ᵀ
A_s = Lᵀ A0 N
z_inf(T) = N exp(A_s T) Lᵀ z0
```

built from rank-revealing null bases and never from inverting the full eigenvector matrix, whose
condition number here is ~5e10. Every endpoint output is required to be finite, real within a
declared tolerance, and strictly positive.

## 8. Finite-`κ` diagnostic — not a proof

The sequence `κ ∈ {10², 10³, 10⁴, 10⁵, 10⁶}`, evaluated by the full-state matrix exponential, is
retained **as a diagnostic only**. It cannot establish the Theorem: it is a finite sample of
trajectories, and its accuracy degrades with `κ` for reasons unrelated to the limit.

Observed behaviour is U-shaped — the error falls to a minimum near `κ ≈ 10³` and then rises. The
rise is a property of the *measurement method* (`‖A(κ)T‖` grows linearly in `κ`, so the conditioning
of `expm` degrades) rather than of the limit. **That interpretation is a diagnostic reading, not a
proved error law**, and no universal `O(κ·eps)` claim is made.

Dispositions:

| disposition | meaning | blocks assurance |
|---|---|---|
| `consistent` | the sequence attains the declared tolerance and does not subsequently rise | no |
| `method_limited` | attains the tolerance, then rises within the declared absolute cap | **no** |
| `inconsistent` | never attains the tolerance, or exceeds the cap | **yes**, until explained by a separately frozen and tested method limitation |

No criterion is fitted to the observed 27 trajectories; the tolerance and the cap are declared in the
producer and are chosen from double precision on operators of this size.

## 9. Coverage

27 operator-distinct cells cover all 54 declared variety–solute–condition cells. The deduplication is
proved, not assumed: **the pencil `(A0, A1, z0, T)` depends on `(solute, temperature, pressure)`
only.** Variety enters the programme solely through the measured `y`, which is never read by this
construction. Each operator-distinct cell therefore covers both varieties.

No cell may be removed because its assumption result is inconvenient.
